# PlaceMap AI – Enterprise Placement Assessment Suite

**PlaceMap AI** is a full-stack web application designed to help students prepare for placements through assessments, resume building, performance tracking, and job application management.

**Project Status:** In Progress

## Key Features
- Secure authentication using JWT and bcryptjs.
- Resume builder with rule-based ATS score estimation.
- Timed aptitude assessments with randomized questions and server-side scoring.
- Assessment review and history tracking.
- Job description saving and application tracking.
- Dashboard with real application data and performance analytics.
- Dark mode and collapsible sidebar.

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** JWT, bcryptjs
- **Other Tools:** Recharts, Zod, Lucide React

## Upcoming Features
- Online coding platform using Judge0.
- AI-powered mock interviews and career coaching.
- Admin dashboard and management features.
- Resume upload, PDF export, and cover letter generation.
- Gemini AI integration.

## Run Locally
1. Clone the repository.
2. Install backend and frontend dependencies.
3. Configure environment variables in the backend `.env` file.
4. Start the backend using `npm run dev`.
5. Start the frontend using `npm run dev`.

## Testing
- Backend test suite: 14 passing tests (as currently reported).
- Tests are designed to run without a database connection.

*Note: The ATS score is an indicative rule-based estimate, not an actual company ATS score. Aptitude questions currently contain sample content.*
